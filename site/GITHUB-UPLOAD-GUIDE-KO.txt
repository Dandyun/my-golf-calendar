My Golf Calendar — GitHub Pages 업로드 안내

1. 이 ZIP 압축을 풀고 다음 파일을 본인 Repository 최상위 경로에 넣으세요.
   - site/index.html, site/app.js, site/styles.css, site/courses.js, site/course-api-cache.js, site/.nojekyll
   - scripts/update_golfcourseapi.py
   - .github/workflows/deploy.yml (기존 파일 덮어쓰기)
   사이트가 site/site/index.html 경로에 잘못 업로드되지 않도록 주의하세요.
2. 새 API 키를 공개 코드에 적으면 안 됩니다.
   GitHub Repository > Settings > Secrets and variables > Actions
   > New repository secret > Name: GOLFCOURSEAPI_KEY > Secret: 본인의 키 > Add secret
3. Settings > Pages > Build and deployment > Source: GitHub Actions
4. Commit changes 후 Actions 에서 `Deploy My Golf Calendar (Static + GolfCourseAPI)` 작업 성공 확인.
5. https://dandyun.github.io/my-golf-calendar/ 접속. 화면이 예전 모습이면 시크릿 창에서 접속.

키를 등록하지 않아도 앱이 작동합니다. 다만 실제 API 스코어카드 데이터는 추가되지 않습니다.
키 등록 후 Actions > Run workflow 버튼을 눌러야 새 데이터가 포함됩니다.
API는 배포 때만 호출되며 웹페이지에 비밀 키가 공개되지 않습니다.
요금과 사용자 리뷰는 실시간 데이터가 아니며, 저장된 일정은 예약이 아닙니다.
반경은 주행 거리가 아니라 지도 중심에서 골프장까지 직선거리(마일)입니다.
